# Add a route

Routing is **file-based**: the filename becomes the URL. `src/app/routeTree.gen.ts` is generated by `tsr generate` / the Vite plugin — never edit it by hand.

Routes are **thin**: they pick a page component and optional `head`/`loader`, and hold no JSX or business logic. The page itself lives in its own FSD slice.

## Steps

1. Create the page slice first:
   - `src/pages/<name>/ui/<name>-page.tsx` — the page component
   - `src/pages/<name>/index.ts` — the slice's public API
2. Create the route file in `src/app/routes/`:
   - `src/app/routes/users.tsx` → `/users`
   - `src/app/routes/users/$id.tsx` → `/users/:id`
3. Use `createFileRoute` with the **exact** path, importing the page through its public API:
   ```tsx
   import { createFileRoute } from '@tanstack/react-router';
   import { UsersPage } from '@/pages/users';
   import { pageTitle } from '@/shared/config/site';

   const head = () => ({ meta: [{ title: pageTitle('users/') }] });

   export const Route = createFileRoute('/users')({
     head,
     component: UsersPage,
   });
   ```
4. For data, prefer a **loader** that prefetches into the Query cache so navigation is instant:
   ```tsx
   import { queryClient } from '@/shared/lib/query-client';
   import { usersQuery } from '@/features/users';

   export const Route = createFileRoute('/users')({
     head,
     loader: async () => {
       await queryClient.ensureQueryData(usersQuery());
     },
     component: UsersPage,
   });
   ```
   Pages read loader data with `getRouteApi('/users').useLoaderData()` so
   they never import `app`.
5. Generate + typecheck:
   ```sh
   pnpm typecheck      # runs `tsr generate` before tsc
   ```

## Conventions

- Routes export `Route` (the `react-refresh` rule is disabled for `src/app/routes/**`).
- Link with typed `<Link to="/users" />` — paths are type-checked.
- Keep route files thin; composition lives in `src/pages/<slice>`.
