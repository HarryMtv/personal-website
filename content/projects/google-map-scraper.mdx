## Why

Local cafés, salons and studios in Prague often live on a Google Maps pin and an Instagram page, with no website of their own. Finding them by hand — checking whether the Maps link is a real domain or just a Facebook profile, hunting for an email when there is no domain to query, and writing a tailored pitch in Czech — was repetitive enough to deserve a dedicated desktop tool.

## What it does

- Scrapes Google Maps with Playwright (`playwright-extra` + stealth), classifying the authority link so businesses with only Facebook/Instagram still count as "no website" while keeping their social URL
- Runs a free-first email cascade for domainless leads: Facebook/Instagram bio and `/about` pages (0.9) → Czech ARES business register API (0.8) → `firmy.cz` directory (0.7) → opt-in Hunter.io fallback (0.4)
- Inspects social profiles in a headless browser to confirm whether the bio hides a real website or only a booking/link-in-bio service, while opening the profile in the system browser
- Generates personalized outreach messages via a two-pass LLM pipeline (Google Gemini or z.ai): pass 1 drafts the offer from the business's name, category, city and target channel (`instagram_dm`, `facebook_dm`, `email`); pass 2 runs a strict native-speaker proofreader that fixes grammar, morphology and diacritics without changing tone or length
- Manages leads across jobs in a local `better-sqlite3` database with a TanStack Table view, bulk actions, a `New → Contacted → Won / Lost` kanban pipeline, and CSV export

The app is split across Electron's three processes (`main`, `preload`, `renderer`) with a strict boundary: all Playwright browsers, HTTP calls, `better-sqlite3` repositories, raw SQL migrations and LLM requests live in `main`. The React 19 + shadcn/ui renderer talks to `main` exclusively through a typed `contextBridge` API (`contextIsolation: true`, `nodeIntegration: false`) with Zod validation at the IPC boundary and streaming progress events for long-running scrape and bulk-email jobs.

## What I learned

Standard email finders start from a domain. When the whole point is finding businesses without a website, there is no domain to feed them. Treating a social link on Google Maps as both a "no website" signal and the first hop of the email cascade — followed by Czech public registries (ARES and `firmy.cz`) — finds contacts before touching paid API credits.

A single LLM prompt in a heavily inflected language like Czech either reads like a translation or rewrites the offer when asked to "make it natural". Splitting message generation into a template-driven draft pass (`{{name}}`, `{{category}}`, `{{city}}`, `{{channel}}`) and a constrained native-speaker proofreader pass — allowed to fix only case agreement, verb aspect, prepositions and diacritics — keeps the pitch intact while reading like a native wrote it.
